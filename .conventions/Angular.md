# Angular Conventions

*This project does not use Angular, but conventions are provided for completeness.*

## File Structure
- Modules: `*.module.ts`
- Components: `*.component.ts` and `*.component.html`
- Services: `*.service.ts`

## Naming
- Classes & Interfaces: `PascalCase`
- Variables & Functions: `camelCase`
- Templates: kebab-case.

## Styling
- Use SCSS with component‑level encapsulation.
